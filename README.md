# Gerador de Senhas em Python

Projeto simples desenvolvido em Python que gera senhas aleatórias com letras, números e caracteres especiais.

## Tecnologias usadas
- Python
- Biblioteca random
- Biblioteca string

## Como executar

Execute no terminal:

python3 password_generator.py

Depois digite o tamanho da senha desejada.

## Exemplo

=== GERADOR DE SENHAS ===
Digite o tamanho da senha: 10

Senha gerada: aF$9!kP2#Q
